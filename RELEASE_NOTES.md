# MaxRunway 0.2.0

- Added ChatGPT sign-in/status through the supported Codex client flow.
- Added Codex-managed Runway MCP configure, sign-in, and status controls.
- Added Omega Plus vision analysis with an editable model ID and HTTPS endpoint.
- Added Windows Credential Manager storage for the Omega Plus API key.
- Added four-point native-versus-generated evidence extraction and structured visual QC.
- Added the tested full-rate 640×360 V-Ray guide plus 2–9 sparse native 4K anchor workflow; the default is eight anchors.
- Bundled the authored IMPACT-inspired lighting recipe library as a read-only, scene-audit-first guide.
- Added a fail-closed final gate: UHD delivery can pass while material fidelity remains unverified or fails.
- Added Autodesk Application Plug-in Package metadata and per-user installer/uninstaller.
- Kept native V-Ray EXR masters isolated from all generative output.

Compatibility target: 3ds Max 2026 and V-Ray 7.x. The release was constructed and smoke-tested in 3ds Max 2026.2 with V-Ray 7.30.02. The requested V-Ray 7.2 build still requires confirmation on the destination workstation.
